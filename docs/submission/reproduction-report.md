# 외부 재현 증빙 (GMCP-48 / GMCP-30 DoD)

팀 외부 인원 1명이 [Quick Start](../quickstart.md)만 보고 5분 데모를 재현한 기록을 남깁니다.

## 재현 요청 템플릿

다음을 재현자에게 전달합니다.

1. 저장소: `https://github.com/2026-OSS-Contest/GuradMCP-KR`
2. 문서: `docs/quickstart.md` (또는 영문 `quickstart.en.md`)만 사용
3. 구두 도움·팀 슬랙 힌트 금지
4. 포트 충돌 시 문서의 **포트 오버라이드** 블록 사용 가능
5. 결과: OS/Docker 버전, 소요 시간, `docker compose ps` 스크린샷, 막힌 단계
