# SCR-302 — Policy empty-state copy

**English** | [한국어](scr-302-empty-state.md)

Use the following copy and links when the Policy list is empty.

- **Title:** No policies yet
- **Body:** Copy an example from the Policy Authoring Guide to create your first policy, then verify it safely with validation and the benchmark.
- **Primary CTA:** `Open Policy Authoring Guide`
- **Primary link:** `/docs/policy-guide/README.en.md`
- **Secondary CTA:** `View default policy-pack examples`
- **Secondary link:** `/policy-packs/default/`
- **Supporting copy:** You can contribute a YAML policy without writing application code.

Include the destination in the accessible name: `Open Policy Authoring Guide in a new tab`. Remove “in a new tab” if navigation remains in the same window. Do not use disabled toggles or error-red styling for an ordinary empty state.

If the application cannot serve repository-relative documents, link to the same path on the repository's `main` branch while preserving the copy and link text.
