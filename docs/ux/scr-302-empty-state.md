# SCR-302 — Policy 빈 상태 문구

[English](scr-302-empty-state.en.md) | **한국어**

Policy 목록이 비어 있을 때 아래 문구와 링크를 그대로 사용합니다.

- **제목:** 아직 정책이 없습니다
- **본문:** 정책 작성 가이드의 예제를 복사해 첫 정책을 만들고, validation과 benchmark로 안전하게 확인하세요.
- **Primary CTA:** `정책 작성 가이드 열기`
- **Primary link:** `/docs/policy-guide/README.md`
- **Secondary CTA:** `기본 정책팩 예제 보기`
- **Secondary link:** `/policy-packs/default/`
- **보조 문구:** 코드를 작성하지 않아도 YAML 정책으로 기여할 수 있습니다.

접근성 이름에는 목적을 포함합니다: `정책 작성 가이드 새 창에서 열기`. 링크가 같은 창에서 열리면 "새 창"을 제거합니다. 빈 상태에는 비활성 toggle이나 오류처럼 보이는 붉은색을 사용하지 않습니다.

GitHub Pages가 아닌 애플리케이션에서 상대 경로를 제공할 수 없다면 repository의 `main` branch 해당 경로로 연결하되, link text와 문구는 유지합니다.
