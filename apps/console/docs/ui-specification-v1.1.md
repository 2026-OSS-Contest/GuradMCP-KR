## 1. 문서 개요

### 1.1 목적

기획서 10.7의 화면 스케치를 구현에 쓸 수 있게 상세화한다. 화면마다 요소 목록, 상태(로딩/빈/오류), 인터랙션, 연동 API를 적고, 기획서 8.5 API로 커버가 안 되는 부분은 6.2에 신규 API로 모아 표기한다.

노란색 텍스트 영역은 개발 참고 정보이며, 화면 UI에 노출하지 않는다. 디자이너는 해당 영역을 시각화하지 않아도 된다.

### 1.2 화면 ID 체계

`SCR-{영역}{일련번호}` 형식. 영역 번호는 레일 내비 순서를 따른다.

| 영역 번호 | 영역                     |
| --------- | ------------------------ |
| 000       | 공통 셸 (레일 + 상태 바) |
| 1xx       | Gateway                  |
| 2xx       | Demo & Live Console      |
| 3xx       | Replay / Policies        |
| 4xx       | Detector / Approval      |
| 5xx       | Settings                 |

### 1.3 표기 규칙

- 요소 표의 "유형"은 버튼 / 링크 / 칩 / 배지 / 목록 / 테이블 / 입력 / 토글 / 인디케이터 / 모달 중 하나로 쓴다.

- 컴포넌트명이 굵게 표기된 것(예: **Verdict Badge**)은 기획서 10.6의 공통 컴포넌트를 그대로 쓴다는 의미다.

- 우선순위 M/S/N은 기획서 6장과 같은 기준.

### 4.2 공통 상태 규칙

| 상태                  | 규칙                                                                                                                                      |
| --------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| 로딩                  | 스켈레톤 표시. 500ms 이내 응답 시에는 스켈레톤을 띄우지 않는다(깜빡임 방지)                                                               |
| 빈 상태               | 안내 문구 1~2문장 + 행동 버튼 1개. 화면별 문구는 5장에 정의                                                                               |
| 오류                  | 원인 + 다음 행동을 함께 쓴다(기획서 10.9). 예: "게이트웨이에 연결할 수 없습니다. docker compose ps로 gateway 컨테이너 상태를 확인하세요." |
| 게이트웨이 미연결     | 전역 배너(노랑 틴트)를 상태 바 아래 고정 표시. SCR-201의 실행 버튼은 비활성화                                                             |
| SSE(실시간 연결) 끊김 | "실시간 연결이 끊겼습니다. 재연결 중…" 인라인 표시, 지수 백오프 재연결(간격을 점점 늘리며 연결 재시도). 복구 시 끊긴 구간은 폴링으로 보충 |

### 4.3 판정 표기 규칙

판정은 전 화면에서 **Verdict Badge**로만 표기한다. 색 단독, 아이콘 단독, 텍스트 단독 표기는 금지(기획서 10.10).

| verdict          | 배지          | 색        |
| ---------------- | ------------- | --------- |
| allow            | [✓ 허용]      | 초록 계열 |
| warn             | [△ 경고]      | 노랑 계열 |
| require_approval | [⏸ 승인 대기] | 보라 계역 |
| block            | [■ 차단]      | 빨강 계열 |

### 4.4 단축키

| 키        | 동작                                                    | 적용 화면 |
| --------- | ------------------------------------------------------- | --------- |
| Space     | 재생 / 정지                                             | SCR-301   |
| ↑ / ↓     | 이전 / 다음 이벤트                                      | SCR-301   |
| Shift+B   | 다음 block 이벤트로 점프                                | SCR-301   |
| B / M / A | 차단 / 마스킹 후 승인 / 그대로 승인 (포커스된 카드에만) | SCR-402   |

### 4.5 반응형·접근성

- 1280px 기준 설계. 1024px 이하에서 우측 상세 패널은 슬라이드오버로 전환(기획서 10.5).

- 타임라인 `role="log"`, 실시간 스트림 `aria-live="polite"`, 인장은 `aria-hidden` 처리(기획서 10.10).

- 모든 모션은 `prefers-reduced-motion`(운영체제의 동작 줄이기 설정) 존중.
